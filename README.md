# OneCare customer support demo

OneCare is a self-contained concept demo that combines billing assistance, home-network troubleshooting, and real-time agent support in a single customer case. It includes three interactive resolution scenarios, a narrated executive walkthrough, and an illustrative Microsoft reference architecture.

## Run locally

Open `index.html` in a modern browser, or serve the repository directory with any static web server, for example:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

No build step, package installation, or backend is required. Scenario data and actions are simulated in the browser. The Microsoft architecture is a reference design, not a claim of production integrations.
